A Python program (standard library only, no network, deterministic) that writes a single funny toaster error message to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
